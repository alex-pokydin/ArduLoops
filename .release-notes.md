### What's in 2.4.6

Parameters load faster on slow links, for example UDP through a radio. Before, they came one by one and the link could stop.

- **Parameter file retry**  - If the vehicle does not answer the first parameter file request, the app asks again after a few seconds. All parameters then come as one file.
- **Faster start**  - The app waits less time for the parameter file. When there is no answer, it changes to the list method sooner.
- **Parameter list**  - Without the parameter file, the app asks for the full list one time. The vehicle sends all parameters. Then the app asks only for the missing ones.
- **Stable link**  - The app sends fewer parameter requests. A slow link stays connected while parameters load.
