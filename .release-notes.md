**ArduLoops 2.2.2** — a version line in Options, and a quieter assistant setup.

### What's in 2.2.2

- **Version** — Options shows this build. When GitHub has a newer one, the gear gets an amber dot and the line reads `2.2.1 (2.2.2)` with a link to that release. The check runs in the background and does not block an offline session.
- **Assistant** — ArduLoops Cloud sits on the same row as the title. **Use my own key** opens when a local key is already saved, and stays folded otherwise.

Link is unchanged from 2.2.1: TCP, UDP (including a WiFi vehicle), and a named serial port. Windows and Linux still download official SITL on **Start**. macOS still ships the bundled Copter SITL. Android is still a link client.

Questions, feedback, and suggestions: [open an issue](https://github.com/alex-pokydin/ArduLoops/issues/new).
