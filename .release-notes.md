**ArduLoops 2.0.0** — the assistant, onboard logs, and vehicle setup on the same station.

### What's in 2.0.0

- **Assistant** — reads the link, the parameters, and a downloaded DataFlash log. A number in the reply is a measurement that log returned.
- **Logs** — onboard list with firmware, frame, and duration. One bad timestamp no longer turns the duration into millions of hours. Download a file and the assistant can measure tracking error, a hold, and a spectrum.
- **Setup** — frame, motors, radio, level, compass, flight modes, failsafe, and battery.
- **Parameters and firmware** — the list on this vehicle, and the firmware library.
- **Audit** — what was written.

Link is unchanged from 1.4.0: TCP, UDP (including a WiFi vehicle), and a named serial port. Windows and Linux still download official SITL on **Start**. macOS still ships the bundled Copter SITL from 1.3.0. Android is still a link client.

### Install

**Windows** — NSIS setup or MSI. **Linux** — `.deb`, `.rpm` or AppImage. **macOS** — `.dmg` (unsigned; Gatekeeper will warn). **Android** — `ArduLoops_2.0.0_aarch64.apk` (sideload; signed so Android will install it).

Open **SITL**, pick a thumb, **Start** — or Link an existing vehicle.

### From source

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173 (needs Node.js and Rust). Installer: `npm run build`. A local Mac installer needs `scripts/build-sitl-macos.sh` first.
