### What's in 2.4.1

The desktop app can now update itself on Windows and Linux.

- **In-app update**  - Options shows an Update button when a newer release is available. The app downloads the signed installer, installs it, and restarts. On macOS, open the release page to update.

This is the first release with the updater. To get it, install 2.4.1 manually one time.

Questions, feedback, and suggestions: [open an issue](https://github.com/alex-pokydin/ArduLoops/issues/new).
