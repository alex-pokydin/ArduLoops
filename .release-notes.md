**ArduLoops 2.1.0** — Lua on the vehicle, plane setup, cloud AI, and a mission map.

### What's in 2.1.0

- **Lua** — read the scripts on the vehicle, edit one, and send it back. Scripting turns on with `SCR_ENABLE`.
- **Plane tools** — servo outputs, airspeed, and plane failsafe sit with the other setup wizards. The assistant opens the wizard that matches the vehicle on the link.
- **Cloud AI** — the assistant can run through an ArduLoops Cloud account. A document it saves comes back as a link on the turn.
- **Missions** — draw a route, set the altitude and the finish (RTL or loiter), and upload it.
- **Phone layout** — sticks, modes, knobs, and the loop notes fold away, and the log keeps at least its previous height.
- Fixes, edits, and smaller work across the link, the plots, the assistant, and SITL.

Link is unchanged from 2.0.0: TCP, UDP (including a WiFi vehicle), and a named serial port. Windows and Linux still download official SITL on **Start**. macOS still ships the bundled Copter SITL. Android is still a link client.

### Install

**Windows** — NSIS setup or MSI. **Linux** — `.deb`, `.rpm` or AppImage. **macOS** — `.dmg` (unsigned; Gatekeeper will warn). **Android** — `ArduLoops_2.1.0_aarch64.apk` (sideload; signed so Android will install it).

Open **SITL**, pick a thumb, **Start** — or Link an existing vehicle.

### From source

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173 (needs Node.js and Rust). Installer: `npm run build`. A local Mac installer needs `scripts/build-sitl-macos.sh` first.
