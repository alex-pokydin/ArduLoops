**ArduLoops 1.1.0** — Linux in-app SITL and GitHub Windows installers.

HEARTBEAT mounts **copter** or **plane**. **Start** on the SITL rail works on Windows and on Linux x86_64.

### What's in 1.1.0

- **SITL** — Linux x86_64 **Start** downloads firmware `arducopter` / `arduplane` (`SITL_x86_64_linux_gnu`) into `~/.local/share/ArduLoops/sitl`. Windows still uses the Mission Planner sitl-exe. Same Link `tcpout:127.0.0.1:5770`. No aarch64 / macOS in-app binary — Link a SITL you start yourself.
- **Installers** — GitHub Actions builds Windows NSIS/MSI and Linux `.deb` / `.rpm` / AppImage on a tag or on workflow_dispatch.

### Install

**Windows** — NSIS setup or MSI. **Linux** — `.deb`, `.rpm` or AppImage.

Open **SITL**, pick a thumb, **Start** — or Link an existing vehicle.

### From source

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173 (needs Node.js and Rust). Installer: `npm run build`.
