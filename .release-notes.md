**ArduLoops 2.2.1** — faster chat, Cloud in the header, and a shared tool budget.

### What's in 2.2.1

- **Chat** — the user message and **Thinking…** show as soon as you send. Confirm or reject a proposal without waiting for the next model step.
- **Cloud** — the header says Cloud when the assistant uses the hosted session, and the provider name when you use your own key. Session refresh stays on the API. A turn stops at 100 tools on both paths.
- **Mission map** — dragging the map no longer selects nearby text.

Link is unchanged from 2.2.0: TCP, UDP (including a WiFi vehicle), and a named serial port. Windows and Linux still download official SITL on **Start**. macOS still ships the bundled Copter SITL. Android is still a link client.

Questions, feedback, and suggestions: [open an issue](https://github.com/alex-pokydin/ArduLoops/issues/new).
