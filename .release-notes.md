**ArduLoops 1.4.0** — UDP to a WiFi vehicle, and a serial port on the desktop.

### What's in 1.4.0

- **Link** — TCP, UDP, or serial. TCP is `host:port`. UDP is a listen port, or `host:port` to send to the vehicle. Serial lists the port’s device name and a baud rate (115200).
- **ESP8266 / MAVLink WiFi** — `host:14550` also sends to port 14555, which is where the bridge listens, and keeps the reply.
- **Android** — arm64 APK, link client only. Start and Stop SITL stay off the phone. The header sits below the status bar.

Windows and Linux still download official SITL on **Start**. macOS still ships the bundled Copter SITL from 1.3.0.

### Install

**Windows** — NSIS setup or MSI. **Linux** — `.deb`, `.rpm` or AppImage. **macOS** — `.dmg` (unsigned; Gatekeeper will warn). **Android** — `ArduLoops_1.4.0_aarch64.apk` (sideload; signed so Android will install it).

Open **SITL**, pick a thumb, **Start** — or Link an existing vehicle.

### From source

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173 (needs Node.js and Rust). Installer: `npm run build`. A local Mac installer needs `scripts/build-sitl-macos.sh` first.
