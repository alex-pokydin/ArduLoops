### What's in 2.4.2

The Android app installs over the previous version again. ArduLoops Cloud now counts AI credits and uses one model.

- **Android update fix**  - 2.4.1 for Android had the wrong version number, so Android did not install it over 2.4.0. 2.4.2 has the correct number. You do not have to remove the app first.
- **AI credits**  - Options shows the AI credits that are left. The plan name next to ArduLoops Cloud opens the plans page.
- **One Cloud model**  - Cloud uses one model for all questions and logs. The model menu is not shown when you use Cloud. With your own key, you still select the model.
- **Log tools**  - When the assistant gives a wrong log name, the tools read the attached log.
