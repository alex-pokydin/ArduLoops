### What's in 2.3.1

The assistant analyzes flight logs directly, tracks token consumption and costs in real time, and synchronizes model pricing from models.dev.

- **Flight-log analysis**  - Local tools and assistant commands calculate compass calibration (magfit), review notch filters, check motor balance, and score PID performance from DataFlash logs.
- **Log audit**  - An automated check scans flight logs for sensor health, vibration levels, and power stability.
- **Token and cost tracking**  - The chat displays token consumption and request costs across tools and turns in real time.
- **Model pricing sync**  - ArduLoops updates model pricing from models.dev with a local cache fallback.
- **Top model selection**  - The model picker surfaces flagship models for each provider.
- **Upstream sync checks**  - A new tool tracks synchronization status against upstream ArduPilot components.

Questions, feedback, and suggestions: [open an issue](https://github.com/alex-pokydin/ArduLoops/issues/new).
