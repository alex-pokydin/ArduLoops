### What's in 2.2.5

Cloud documents are private until you share them, and you can preview them in ArduLoops.

- **Document preview** — Click a saved document card or link in the assistant to open the document in a window. You can share or stop sharing the document from that window.
- **Private documents** — New cloud documents are only visible to the owner. A closed link asks the visitor to sign in and request access.
- **Personal links** — In ArduLoops Cloud, you can approve an access request or enter an email address to create a personal link for one user.
- **View counter** — Each document and personal link shows the number of views.
- **Cloud Markdown** — ArduLoops Cloud renders Markdown tables and math formulas.

Questions, feedback, and suggestions: [open an issue](https://github.com/alex-pokydin/ArduLoops/issues/new).
