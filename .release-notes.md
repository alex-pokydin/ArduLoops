### What's in 2.2.2

Options shows this version. The assistant title includes the Cloud link.

- **Version**  - Options shows this version. If GitHub has a new version, an amber dot shows on the Options button. The line shows `2.2.1 (2.2.2)` with a link to that release. The check occurs in the background. The app operates if there is no network.
- **Assistant**  - The ArduLoops Cloud link is on the same line as the title. If you saved an API key, **Use my own key** is open. If you did not save a key, this section is closed.
