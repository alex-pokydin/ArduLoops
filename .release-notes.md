**ArduLoops 2.2.0** — gyro spectrum from a log, L1 on the mission map, and phone sign-in.

### What's in 2.2.0

- **Spectrum** — the assistant draws the gyro spectrum, or a spectrogram, under the reply when the answer is about that frequency. The filtered capture and the notch from the log are on the picture when the file has them.
- **Notch knobs** — mode, reference, frequency ratio, and attenuation sit with enable, frequency, and bandwidth.
- **Plane mission** — **Show L1 track** draws the look-ahead circle, Nu, and the cross-track error from `NAVL1_PERIOD`, `NAVL1_DAMPING`, `WP_RADIUS`, and cruise. **Clover** drops a preset. **Restart in AUTO** is `MIS_RESTART`.
- **Simulator** — a SITL link is marked as a simulator, so a missing board id does not hold the firmware library on a filter.
- **Android sign-in** — Google opens in the phone browser and returns through `arduloops://auth`. Cloud session refresh and chat go through the API with Mozilla TLS roots. The Firebase web key stays on the server, not in the app.
- The start page points at short pages for loops, SITL, setup, logs, missions, Lua, and the assistant.

Link is unchanged from 2.1.0: TCP, UDP (including a WiFi vehicle), and a named serial port. Windows and Linux still download official SITL on **Start**. macOS still ships the bundled Copter SITL. Android is still a link client.
