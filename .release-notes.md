### What's in 2.3.0

The assistant accepts images, keeps the log of a chat, and suggests the next step. Errors and long tool runs are easier to follow.

- **Images**  - Paste a screenshot, drop an image on the chat, or use **+** to add up to 4 images to a message. ArduLoops makes large images smaller before it sends them.
- **Next step buttons**  - The assistant can show up to 4 buttons under a reply. A button puts its full text in the message box. You can change the text before you send it.
- **Log of the chat**  - A log that you attach stays with the chat. The next questions in that chat use the same log. The assistant compares the board ID in the log with the connected vehicle.
- **Log list**  - The log list shows the file name, the board, the flight time, and the size. You can search by name, board, or date, and show only the logs of the connected vehicle. The list opens much faster.
- **Your own log files**  - A log that you load keeps its file name. A progress bar shows the upload and the check of the file.
- **Model menu**  - Select the model and the reasoning level in one menu. The model lists include the latest Gemini, OpenAI, Anthropic, and xAI models for your own keys.
- **Clearer errors**  - An error shows the message from the provider. Use **Retry** to send the same message again. Use **Copy** to copy a reply.
- **Run timer**  - A timer shows how long the current step and the full turn run.
- **Fixes**  - Tool calls with incomplete arguments no longer stop the chat with an error. Anthropic replies are no longer cut at a low token limit.
