**ArduLoops 1.2.0** — one-page studio, header pause, plot window.

Copter and plane share the same layout: map, loop scheme, and traces together. Pause freezes the picture; MAVLink still runs.

### What's in 1.2.0

- **Studio** — map left, loop top-right, traces bottom-right. Expand a pane; drag the gutter (kept per frame).
- **Pause** — in the header next to the title. Attitude, map, loop and plots freeze; link / SITL / STATUSTEXT keep moving. Space toggles it.
- **Plot window** — Options: 8 / 15 / 30 / 60 s. A one-minute ring buffer keeps filling during pause, so traces already have history.
- **Watch** — any live field, with search. Extra knobs sit under the scheme when you click a block.
- **Plane** — L1 and TECS as readable schemes; click a TECS block on the expanded loop for extra limits.
- **SITL** — Start/Stop on one control; Pause / Reset while the sim is running.

### Install

**Windows** — NSIS setup or MSI. **Linux** — `.deb`, `.rpm` or AppImage.

Open **SITL**, pick a thumb, **Start** — or Link an existing vehicle.

### From source

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173 (needs Node.js and Rust). Installer: `npm run build`.

### Not in this release

- QuadPlane, autoland flare
- Full harmonic-notch wizard (harmonics, HNTC2, MODE)
- Conventional ArduPilot tuning workflow (Mission Planner / log protocol)
- In-app SITL on ARM or macOS
