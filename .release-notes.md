**ArduLoops 1.3.0** — macOS installers, with SITL inside the app.

### What's in 1.3.0

- **macOS** — Apple Silicon and Intel `.dmg` from GitHub Actions.
- **SITL on Mac** — the release job builds ArduPilot `Copter-4.7.0` (`arducopter` / `arduplane`) and packs it into the app. **Start** launches that copy and links `tcpout:127.0.0.1:5770`.

Windows and Linux still download official SITL on **Start**.

### Install

**Windows** — NSIS setup or MSI. **Linux** — `.deb`, `.rpm` or AppImage. **macOS** — `.dmg` (unsigned; Gatekeeper will warn).

Open **SITL**, pick a thumb, **Start** — or Link an existing vehicle.

### From source

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173 (needs Node.js and Rust). Installer: `npm run build`. A local Mac installer needs `scripts/build-sitl-macos.sh` first.

### Not in this release

- QuadPlane, autoland flare
- Full harmonic-notch wizard (harmonics, HNTC2, MODE)
- Conventional ArduPilot tuning workflow (Mission Planner / log protocol)
- In-app SITL on Linux ARM
